# Пульс ИИ

[Публичная лента новостей и ответов GPT](https://dpproekt.github.io/Nov_II/#/updates) · [Журнал поиска](https://github.com/DPProekt/Nov_II/actions/workflows/pulse-news.yml)

Кнопка **Обновить** перечитывает опубликованную ленту и предлагает владельцу запустить облачный поиск. На странице темы обновляется именно эта тема; с главной или из общей ленты — все восемь. В авторизованной панели запрос передаётся агенту автоматически. Если вход во всплывающем окне недоступен, ссылка **Подтвердить через GitHub** открывает подготовленный запрос: редактор отправляет его кнопкой Create. GitHub проверяет его права и закрывает запрос после передачи агенту. Читателям не нужны ключи или локальные программы.

Агент ищет в сети через API в постоянной сессии темы. Ответ с идентификатором запроса появляется в `archive.json`; подтверждённые новые статьи и аналитика — в `news.json`. На сайте дата ответа показана отдельно от даты источника. Отсутствие новых статей допустимо; сам ответ о проверке сохраняется. Версии аналитики хранятся в `analysis-history.json` для сравнения.

Плановые восьмитемные выпуски идут каждые шесть часов. Отдельная очередь ручных запросов на закрытом Sites и служба `deploy/pulse-clock/pulse-ii-manual.timer` на сервере передают GitHub Actions только имя темы и номер запроса. Доступ к OpenAI выдаётся серверному заданию через OIDC. Ключей в клиентском коде нет. Повторный запуск с тем же номером не ищет тему заново, если ответ уже опубликован.

В интерфейсе можно листать шестичасовые периоды, выбирать неделю, месяц или год, открывать аналитику и сравнивать прогнозы. Фильтр шести часов использует только подтверждённое время публикации; статьи с известной лишь датой доступны в более длинных периодах. Сценарные оценки отделены от свершившихся событий.

`news_server.py` и `pulse_dispatch.py` — прежние локальные инструменты. Опубликованному сайту они не нужны.

# Пульс ИИ

Личный архив десяти выбранных чатов GPT о новостях искусственного интеллекта и прогнозах. Исходные ответы находятся в `archive.json`; сайт показывает их с разбивкой по чатам и датам. Один ответ ограничен первыми 20 000 знаков интерфейсом извлечения. Сведения и прогнозы на страницах не являются заново проверенными фактами.

Кнопка «Обновить» перечитывает опубликованный архив. Прямого подключения сайта к закрытым чатам GPT пока нет, поэтому новые ответы она самостоятельно не извлекает. Для подлинного обновления потребуется поддерживаемое и авторизованное подключение к чатам.

Статический сайт состоит из `index.html`, `style.css`, `app.js` и `archive.json`. Для локального просмотра запустите HTTP-сервер в этой папке.

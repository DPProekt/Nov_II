# Пульс ИИ

Личный архив девяти выбранных чатов GPT о новостях искусственного интеллекта и прогнозах. Исходные ответы находятся в `archive.json`; сайт показывает их с разбивкой по чатам и датам. Один ответ ограничен первыми 20 000 знаков интерфейсом извлечения. Сведения и прогнозы на страницах не являются заново проверенными фактами.

На локальном сервере кнопка «Обновить» ищет в интернете публикации с датой позже последней добавленной новости при помощи OpenAI Responses API и модели `gpt-6.1-terra`. Ключ читается исключительно из переменной окружения `OPENAI_API_KEY` серверного процесса. Данные сохраняются в `private-news.json` (этот файл исключён из Git). Вывод модели, даты и ссылки требуют проверки. Вызовы модели и поиск могут тарифицироваться.

Локальный запуск: `python news_server.py`, затем `http://127.0.0.1:8766/`. Сервер слушает только локальный интерфейс. Опубликованный сайт обращается к серверу только на том компьютере, где работает этот локальный процесс. На другом устройстве или после остановки процесса кнопка не сможет выполнить поиск. Ключ не добавляется в браузер или GitHub Pages.

API-поиск ищет новости в интернете: прямое автоматическое получение новых сообщений из закрытых чатов GPT пока не подключено. Один длинный ответ доступен только в пределах первых 20 000 символов.

Общая лента для всех посетителей хранится в `news.json`; раздел прогнозов использует `forecasts.json`. Периоды: последние шесть часов с листанием, последние семь и последние 30 дней. Для шестичасового фильтра требуется подтверждённое время публикации `published_at`; записи с одной только датой доступны в более широких периодах. `importance: "high"` отмечает наиболее значимые новости. В разделе прогнозов числовой график строится только при наличии сопоставимых сценарных данных и допущений. Пустые файлы не означают, что автоматический сбор уже настроен или работал.
